Firebase Storage rules update for YoPartner partner profile media:

Important:
- Merge this with your current Firebase Storage rules. Do not blindly overwrite unrelated existing rules.
- Apply in Firebase Console > Storage > Rules > Publish.
- Public read is intentional for partner profile photo/gallery because these images are shown publicly on user-facing profile pages.

Use this rule block:

rules_version = '2';

service firebase.storage {
  match /b/{bucket}/o {

    match /YoPartner/partner-kyc/{uid}/{allPaths=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }

    match /YoPartner/partner-profile/{uid}/{folder}/{fileName} {
      allow read: if true;

      allow write: if request.auth != null
        && request.auth.uid == uid
        && folder in ['profile', 'gallery']
        && request.resource.size < 5 * 1024 * 1024
        && request.resource.contentType.matches('image/.*');
    }
  }
}
